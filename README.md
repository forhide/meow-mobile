# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.43.8** — clearer foe states (one badge row over each head, with time-left rings and body tints), miscasts now daze foes (they take more damage, violet numbers), overreactions land like critical hits (big gold numbers), and four mishap-build pieces: Dizzy Bell, Fizzing Fuse, Surge Battery and Apology Scroll.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app starts at index.html and supports offline play after a complete first load.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.43.8** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary. Chromium update/offline and Web Audio checks passed. Actual iPhone/Safari audio and hardware testing remain separate checks. Sound preferences are preserved; Settings → Check sound can help verify output.
