# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.43.1** — fixes missing pictures on iPhone (textures are now GPU-compressed: about 632 MB → 182 MB of graphics memory) and lets a tap on the bottom action notice use it, like Talk. Includes v0.43.0's new music for five scenes, the single gate arrow and painted floor shadows.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app starts at index.html and supports offline play after a complete first load.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.43.1** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary. Chromium update/offline and Web Audio checks passed. Actual iPhone/Safari audio and hardware testing remain separate checks. Sound preferences are preserved; Settings → Check sound can help verify output.
