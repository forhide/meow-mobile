# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.64.0** — Smaller phone controls: the move stick, spell, special and roll buttons are three-quarter size and sit right in the screen corners, leaving more room to see the fight. Everything from v0.63.0 (staged Pip specials, boss awakening and defeat scenes) is included.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app starts at index.html and supports offline play after a complete first load.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.64.0** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary. Local browser music (7/7) and isolated sound-effect checks passed. Actual iPhone/Safari audio, hardware and offline update testing were not done for this build. Sound preferences are preserved; Settings → Check sound can help verify output.
