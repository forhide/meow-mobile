# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.60.0** — Pip gains neutral homing spells and an elemental dragon breath; wand-copy growth, four cleanup mini-events and free reward rerolls/banishes add choices during each expedition.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app starts at index.html and supports offline play after a complete first load.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.60.0** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary. Chromium update/offline and Web Audio checks passed. Actual iPhone/Safari audio and hardware testing remain separate checks. Sound preferences are preserved; Settings → Check sound can help verify output.
