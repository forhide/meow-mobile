# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.44.5** — English buttons and study names stay on one line, the cat's remarks are see-through, the story's Grimoire threads are rune ribbons, the fight seal is easy to spot on grass and Pip's dragon is 1.5x bigger; plus v0.44.4: Pip's mending, fewer gear drops and a faster Sunfizz Scepter.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.44.5** at the bottom left of the title.
