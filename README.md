# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.42.0** — 11 equipped-item pairings, solid fallen bookcases, four soft piano themes, 17 clean effects, and touch/resume audio support.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app starts at index.html and supports offline play after a complete first load.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.42.0** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary. Chromium update/offline and Web Audio checks passed. Actual iPhone/Safari audio and hardware testing remain separate checks. Sound preferences are preserved; Settings → Check sound can help verify output.

Recorded piano: Alexander Holm / Salamander Grand Piano, CC-BY3.0; FLAC/SFZ conversion by kinwie / sfzinstruments. See AUDIO-CREDITS.md and SALAMANDER-LICENSE.txt.
