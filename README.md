# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.62.0** — Playtest repairs: clearer bag, reward and growth panels, readable boss name plates on phones, hedge walls that break after three hits (fire still burns them at once), and a steady gull gust that no longer jitters the cat into corners.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app starts at index.html and supports offline play after a complete first load.

For updates, connect to the Internet, close every game window/tab, and reopen. Check **v0.62.0** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary. Local browser music (7/7) and isolated sound-effect checks passed. Actual iPhone/Safari audio, hardware and offline update testing were not done for this build. Sound preferences are preserved; Settings → Check sound can help verify output.
