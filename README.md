# Meowgnificent the wizard cat — web / phone build

Play: https://forhide.github.io/meow-mobile/

Current build: **v0.41.1** — playtest fixes, solid interaction props, individual ember cleanup, painted elite emblem, wind chicken/dragon summons and a larger version badge.

On iPhone: open in Safari → Share → Add to Home Screen. Turn the phone sideways. The app uses index.html as its start page and supports offline play after a complete first load.

For updates, connect to the Internet, close the game completely (including other tabs running it), and reopen. Check **v0.41.1** at the bottom left of the title. Keep browser/app storage to retain progress; deleting it is unnecessary for an update. Update and offline startup were checked in Chromium; actual iPhone/Safari testing is still needed.
