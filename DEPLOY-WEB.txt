Meowgnificent the wizard cat — Web v0.20.0

ZIP의 index.html과 같은 폴더의 모든 파일을 정적 호스팅에 올리세요.
Godot 설치는 필요 없으며 WebAssembly/WebGL2를 지원하는 데스크톱 브라우저에서 엽니다.
file://로 HTML을 직접 열면 실행되지 않습니다. PC는 키보드·마우스, 휴대폰·태블릿은 터치 조작으로 플레이합니다.
itch.io: HTML 게임에 ZIP 업로드 후 브라우저 실행으로 설정하세요.
GitHub Pages: ZIP 내용 전체와 .nojekyll을 게시 폴더에 올리세요.
스레드 비활성 빌드여서 COOP/COEP 헤더가 필요하지 않습니다.
외부 CDN/원격 리소스 의존성이 없으며 HTTPS 정적 호스팅을 권장합니다.
현재 공개 웹 호스팅에 게시한 상태는 아닙니다.

아이폰·안드로이드 웹앱(오프라인)
1. HTTPS 주소에 올린 뒤 휴대폰 사파리(안드로이드는 크롬)로 엽니다. 처음 한 번은 인터넷이 필요합니다(약 80MB).
2. 공유 버튼 → "홈 화면에 추가". 이후 아이콘으로 전체 화면 실행되며 비행기 모드에서도 플레이됩니다.
3. 가로로 돌려서 플레이합니다. 왼쪽 엄지: 이동 / 별 버튼: 기본 마법(누르는 동안 가까운 적 자동 조준, 끌면 직접 조준) / 지팡이 버튼: 특수기 / 회전 버튼: 구르기 / 오른쪽 위: 일시정지·장비·대화.
4. 세이브는 휴대폰 안에 저장됩니다. 홈 화면 앱을 지우면 세이브도 지워집니다. 새 버전을 올리면 다음 온라인 실행 때 자동으로 받습니다.

조작
WASD/방향키: 이동 | 마우스: 조준 | 클릭/Space: 무기별 기본 마법
Q/마우스 오른쪽 클릭: 착용 주무기의 특수 스킬 | Shift+방향: 구르기
I: 그림 장비창 | E: 친구 대화·페이지 넘김·종료/테이블 앞 구매/관리 통로/열린 출구
Enter: 시작/이야기 다음/클리어 후 다음 구역
Esc: 계속하기·새로 시작·메인 메뉴로/대화·패널 닫기/이야기 건너뛰기 | F10/설정: 한국어·영어
M: 시작·패배·완주 화면에서 영구 강화
상점/영구 강화: 클릭 또는1~4 | F1/F2/F3: 다음 주문 성공/실수/폭주 고정

기본 마법은 주무기에 따라 불·물·얼음·바람·돌·생명·번개·금속로 바뀝니다.
각 속성은 손끝에서 모인 뒤 일렁이는 불덩이·출렁이는 물·소용돌이·회전하는 결정 등으로 날아갑니다.
장비에 커서를 올려 바뀌는 능력의 화살표와 마법을 보고, 선택 후 장착하세요.
장비 85종 중 주무기는 37종이며, 장착한 주무기에 따라 11종 중 Q 특수기 하나를 사용합니다.
불은 메테오, 번개는 체인 라이트닝처럼 속성에 맞는 대표 특수기가 있습니다.
적의 약점·저항을 작은 속성 표시로 확인하세요. 물에 젖은 적에게는 번개가 효과적입니다.
장비를 바꾸어도 남은 특수기 대기 시간은 초기화되지 않습니다.
장착하지 않은 장비는 버리기를 두 번 눌러 정리할 수 있습니다. 다른 장비 선택/창 닫기는 취소입니다.
이야기 화면에서는 A 또는 자동 넘김 버튼으로 자동 진행을 끄고 켭니다.

벌 청소→도서관→금지된 정원→핍의 피크닉→낙제생들의 아지트→반듯한 산책로→마지막 쉼터→대서고의8구역입니다.
8구역 안에 17차례 전투가 이어집니다. 한 무리를 정리한 뒤 지도에 표시된 다음 마법진으로 이동하세요.
구역의 모든 전투를 마쳐야 출구가 열립니다. 도서관의 책은 돌진하고 버섯은 포자를 뿜습니다.
특정 책장이 넘어지면 뒤에 드러난 관리 통로를 E로 조사할 수 있습니다.
불만 책장에 불을 붙이며, 다른 속성이나 구르기로도 책장을 넘어뜨릴 수 있습니다.
상점의 모스·블룹은 E, 핍은 T로 대화합니다. 장비 보기는 핍·중앙 매대에서 E입니다.
완벽의 마도서는 책 자체의 캐릭터입니다. 실수·폭주·몸통/환경 사고로 장벽을 열거나 공격 뒤의 빈틈을 노리세요.

적이 떨어뜨린 크라운·장비·음식은 이번 원정에 사용합니다.
패배하면 크라운과 장비가 초기화되며, 클리어 보상의 별빛·영구 강화·기록은 저장됩니다.
진행 중 원정을 종료한 뒤 같은 지점에서 이어 하는 기능은 없습니다.
기본 UI/대사는 한국어이고 설정의 언어 선택은 다음 실행에도 유지됩니다.
포함된 GODOT-LICENSE.txt는 엔진 라이선스이며 게임 자체의 이용허락을 뜻하지 않습니다.

효과음: 설정 → 끔 / 작게 / 보통. 선택한 음량은 다음 실행에도 유지됩니다.
핍의 상점에서 I로 가방을 열고, I/Esc로 같은 상점에 돌아갑니다.
바닥에 장비가 남으면 I로 가방을 정리하거나, 경고 후 5초 안에 Enter/E를 다시 눌러 두고 떠납니다.

이 버전의 추가 내용
마법 실패 뒤2.8초 동안 그을음이 남습니다. 책장과 테이블은 길을 막으며, 책장은 완전히 쓰러진 뒤 지나갈 수 있습니다. 적3마리마다 연구 별빛을 모으고 패배해도 보유합니다. M 영구 강화는4권·16종·125단계이며 각 노트에서1~4로 연구를 고릅니다. 기존 저장을 자동 이전합니다. 코드/그래픽 인계 파일도 같은 버전으로 제공합니다.

0.18: Permanent studies (M before/after a run) now show all16 choices on one page. Equipped collars replace the cat's original bell. More solid bookcases, carts, supply boxes and garden planters shape each area.

이 버전의 난이도와 상호작용
크리티컬 폭주 반동은 체력5, 마법 실패는 체력10을 소모합니다. 방어·무적으로 줄어들지 않습니다.
통조림으로 회복하세요. 성공한 주문이나 취소한 시전은 체력을 소모하지 않습니다.
미업그레이드 적의 체력·이동 속도·공격 피해와 공격 빈도를 높였습니다.
혼잣말은 고양이 옆 말풍선, 다음 전투 목적은 별도 상태 카드에 표시합니다.
핍을 포함한 모든 친구는 E로 대화하며 마지막 페이지에서 닫힙니다. 읽는 동안 이동은 멈춥니다.
물건은 중앙 테이블 앞에서 E로 삽니다. 화분·친구·닭·표식·출구에는 부피와 충돌이 있습니다.
R 초기화와 T 대화는 사용하지 않습니다. Esc 메뉴에서 재시작·메인 메뉴를 선택하세요.
